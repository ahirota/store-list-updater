PS Quick Store List

PS Quick Store List Guide

Getting Started

  1. List will initialize from store JSON file.
  2. Edit existing store names and URLs as needed.
  3. Add, delete, or reorder stores as required.
  4. Select the states and stores you want to include.
  5. Click Generate Store List.
  6. Copy the generated store list and CSS into your intended destination.

User Interface

Store/State Selection

  • Each state has a checkbox to select or deselect all stores within that state.
  • Each store has a checkbox to select or deselect it for inclusion in the generated output.

Select/Deselect All Stores

  • Quick button to auto select and deselect all states and stores.

Store Editing

  • Click a store's name or URL to edit its contents directly in the list.

Adding Stores

  • Enter a store name and store URL in the form below the relevant state, then click Add.

Deleting Stores

  • Click the × button next to a store to remove it.

Reordering Stores

  • Drag and drop store entries to change their order within a state's list.

Generating the Store List

  • Click Generate Store List to create a formatted output containing the selected states and stores, along with CSS for formatting. Copy the generated content into your target page or document.

Copying the Generated List

  • Click Copy Store List to copy the generated content to your clipboard.

Features

  • Inline Editing: Click a store name or URL to edit it directly.
  • Add New Stores: Use the form to add stores to a state's list.
  • Delete Stores: Remove individual stores from the list.
  • Drag-and-Drop Reordering: Rearrange stores within a state.
  • Checkbox Selection: Select individual stores or entire states for the generated output.
  • Store List Generation: Generate a copy-paste-friendly list of selected stores and states.
  • CSS Formatting: Includes CSS to help format the generated store list.
